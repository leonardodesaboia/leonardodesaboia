# Leonardo de Saboia

**Full Stack Developer · Founder & CTO at AllSet · Fortaleza, Brazil**

I build products from idea to production, connecting business, architecture and code. I'm studying Computer Science at **UNIFOR**, working at **Vortex Lab**, and developing freelance projects at **Eleva**.

Currently building **AllSet**, a mobile-first marketplace for independent service professionals.

## Selected projects

- **AllSet** — A marketplace with scheduled and express services, escrow payments and professional ratings. Built with React Native, Java, Spring Boot and PostgreSQL. [Frontend](https://github.com/leonardodesaboia/TCC-front) · [Backend](https://github.com/leonardodesaboia/TCC-back)
- **SAFE — Hospital IoT** — Hospital bed monitoring with ESP32 and MQTT, alerting nursing staff to fall risks. **2nd place at the ABINC IoT Awards 2025.**
- **Ciudad en Movimiento** — A sports event platform for Paysandú, Uruguay, with a mobile app and an admin panel. International volunteer work as developer and project manager; software registration and a published academic paper.
